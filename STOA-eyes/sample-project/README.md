# Sample project

Three files for Project Check. Select all of them with **Upload project**, or press **Load sample** in the app.

| File | What it says |
| --- | --- |
| `schedule.csv` | Office 1 has 4 windows and 2 doors. Kitchen has 1 window and 1 door. |
| `site-meeting.txt` | Office 1 windows were reduced to 3. Doors stay at 2. |
| `A-201 Office 1.jpg` | Blueprint whose name matches Office 1. No sheet is named for Kitchen. |

The check should report a conflict on Office 1 windows (4 vs 3), a match on Office 1 doors (2 and 2), and no blueprint for the Kitchen counts.
